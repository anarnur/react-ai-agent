# Autonomous ReAct Agent 🤖

Проект автономного ИИ-агента на базе фреймворка **ReAct** (Reason + Act). 
Агент способен «думать вслух», планировать свои действия и использовать внешние инструменты для решения сложных задач.



## ✨ Особенности
- **Цикл автономии:** Модель работает в цикле `Мысль` -> `Действие` -> `Наблюдение`.
- **Инструменты:** - `get_current_date`: Получение системной даты.
  - `calculator`: Выполнение математических операций через Python.
- **Логика:** Агент самостоятельно решает, когда нужно применить инструмент, а когда — дать финальный ответ.

📝 Пример работы
Запрос: "Сколько дней осталось до Нового года и каков корень из этого числа?"

Логика агента:

Мысль: Нужно узнать текущую дату.

Действие: get_current_date() -> 20 февраля 2026.

Мысль: Считаю разницу дней и извлекаю корень.

Действие: calculator("sqrt(315)") -> 17.75.
